### **Design and Implementation of a Relational Database using Oracle Database 19c or a Later Version**  

You are required to design and implement a relational database using Oracle Database version 19c or a later version. The database must contain at least **six independent entities** in the Entity-Relationship Diagram (ERD) and at least **one many-to-many relationship**.  
 

1. **Provide a brief description of the database** (its purpose and utility).  
2. **Create the Entity-Relationship Diagram (ERD):** Entities, relationships, and attributes must be defined in Romanian (as per the Database Management Systems course). No other format will be accepted.  
3. **Based on the ERD, create the conceptual diagram** of the proposed model, integrating all necessary attributes: entities, relationships, and attributes must be defined in Romanian.  
4. **Implement the conceptual diagram in Oracle:** Define all tables, ensuring that all necessary integrity constraints (primary keys, foreign keys, etc.) are included.  
5. **Insert coherent data into the created tables:**  
   - At least **five records for each independent entity**.  
   - At least **ten records for each associative table**.  
6. **Formulate a problem in natural language** and solve it using an **independent stored subprogram that utilizes all three types of collections studied**. Call the subprogram.  
7. **Formulate a problem in natural language** and solve it using an **independent stored subprogram that utilizes two different types of cursors**, with one being a parameterized cursor dependent on the other. Call the subprogram.  
8. **Formulate a problem in natural language** and solve it using an **independent stored function** that involves **three of the created tables in a single SQL command**. Handle all possible exceptions, including the predefined exceptions **NO_DATA_FOUND** and **TOO_MANY_ROWS**. Call the function and demonstrate all handled cases.  
9. **Formulate a problem in natural language** and solve it using an **independent stored procedure** with at least **two parameters** that involves **five of the created tables in a single SQL command**. Define at least **two custom exceptions** (other than the predefined system exceptions). Call the procedure and demonstrate all defined and handled cases.  
10. **Define a command-level LMD trigger.** Trigger the event.  
11. **Define a row-level LMD trigger.** Trigger the event.  
12. **Define an LDD trigger.** Trigger the event.  
13. **Formulate a problem in natural language** and solve it using a **package** that includes **complex data types and objects necessary for an integrated workflow** specific to the defined database. The package must contain:  
   - **At least two data types**  
   - **At least two functions**  
   - **At least two procedures**
